## 🧠 What is Nano GPT Rapper?

**Nano GPT Rapper** is an AI-powered micro-assistant designed for IIT Guwahati freshers, blending powerful GPT intelligence with an engaging rapper persona.

Think of it as **ChatGPT meets Slim Shady** – it answers your queries about IITG life in smooth, witty, rhyme-laced style. Whether it's about hostels, mess food, Wi-Fi, or campus secrets – your rapper buddy's got bars for it all.

---

## 🔥 Features

- 🎤 **Rap-styled Answers** to common fresher FAQs.
- 🏠 **Campus Info** about hostels, mess, common areas, security, connectivity, etc.
- 🤖 **Nano GPT Integration** with minimal latency, optimized for edge deployment.
- 🪄 **Sassy, Snappy, Smart** — responses that entertain and inform.
- 📡 **Offline Mode Ready** – minimal models for resource-tight environments.

## 🏗️ Tech Stack

| Tech | Purpose |
|------|---------|
| `GPT-3.5/4-o` | Core language generation |
| `LangChain` | Query routing and memory |
| `Streamlit` / `Next.js` | Frontend interface |
| `FastAPI` | Backend (API layer) |
| `Pinecone/ChromaDB` | Vector DB for query optimization |
| `Docker` | Easy deployment |

## 🛠️ Setup & Installation

```bash
# Clone this mic-dropping repo
git clone https://github.com/yourusername/nano-gpt-rapper.git
cd nano-gpt-rapper

# Create virtual env and install dependencies
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run the backend
uvicorn app.main:app --reload

# (Optional) Run the frontend
cd frontend
npm install
npm run dev
````
